# Architecture

There is one platform-owned masking gateway API and independently evolved team model services. Each team owns its implementation, private service, tests, model card, safe configuration, and immutable model fingerprint. The gateway is the only externally invoked implementation of `contracts/masking-api/v1.4`, which narrows the `X-Model-Format` enum to `onnx` alone; v1.3 before it added the optional `X-Document-Locale` request header to v1.2.

NiFi owns the trusted routing decision and is model-agnostic. It derives `team_id` only from trusted R2 keys: `incoming/octo/<request-id>/<filename>` becomes `octo`, with equivalent fixed derivations for Synthify and Berts. NiFi calls one configured gateway URL and sends that trusted value in `X-Team-ID`. It never accepts a team, API URL, or target model from file metadata. The gateway validates `octo`, `synthify`, and `berts`, verifies the source-key binding, then sends the request to the mapped private team service. It does not disclose internal endpoints or secrets.

The gateway returns masked bytes and safe headers for team, model name, immutable version, request ID, and latency. Runtime flow is: R2 source upload → NiFi derives trusted `team_id` from object path → NiFi calls one masking gateway API → gateway selects a private model service → gateway returns masked content and immutable model metadata → NiFi writes the result to R2 destination. NiFi records a terminal R2 manifest. MLflow receives one synthetic-evaluation child run per team and immutable model version. No raw PII or production output is logged. See [multimodel deployment](multimodel-deployment.md) for the Compose demo.
