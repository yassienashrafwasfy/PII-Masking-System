# Security policy

Treat every production object, log, model artifact, and environment value as sensitive. This repository accepts synthetic fixtures only. Report suspected exposure through the organization’s private security channel; do not create a public issue containing the secret or PII.

Rotate a disclosed credential immediately, remove the exposed value from reachable history using the approved incident process, and record the remediation privately. Local configuration must use ignored `.env` files; committed examples must contain placeholders.
